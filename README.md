# 월중계획 대시보드 (School Monthly Planner)

초등학교 교무부장교사가 매월 작성하는 **월중계획**을 관리하기 위한 대시보드 웹앱입니다.
행사, 교직원 복무(출장·연수 등), 처리해야 할 공문을 날짜별로 등록하면 달력 형태로 한눈에 볼 수 있고,
결재용 월중계획표(A4 가로)로 바로 인쇄할 수 있습니다. 여러 학교가 함께 사용할 수 있으며,
학교 구성원 누구나 참여코드로 들어와 실시간으로 함께 입력할 수 있습니다.

배포 주소: https://school-monthly-planner.web.app/

## 주요 기능

- **대시보드 달력**: 이번 달 행사 / 복무 / 공문을 색상으로 구분해 달력에 표시
- **날짜 클릭 → 빠른 등록**: 날짜를 클릭하면 그 날의 일정을 보고, 바로 행사/복무/공문을 추가 가능
- **복무 관리**: 대상자, 직위(교장/교감/교무부장/교사/행정직원 등), 구분(출장/연수/조퇴/병가 등), 기간(시작~종료) 기록
- **공문 관리**: 제목, 발신 부서, 처리 상태(처리중/완료) 기록
- **요약 카드**: 이번 달 행사·복무·공문 건수, 처리 대기 공문 건수를 한눈에 표시
- **인쇄용 월중계획표**: 상단 결재란(담당/교무부장/교감/교장)이 있는 A4 가로 표 형식으로 인쇄
- **여러 학교 지원**: 학교마다 데이터가 완전히 분리되며, 참여코드를 아는 사람만 접근 가능
- **실시간 공유**: 같은 학교 구성원이 입력하면 다른 구성원 화면에도 즉시 반영

## 사용 방법

1. 처음 접속하면 이름을 입력합니다.
2. **교무부장(최초 등록자)**: "학교 새로 만들기"로 학교를 등록하면 참여코드가 발급됩니다.
3. **나머지 구성원**: 교무부장에게 받은 참여코드로 "참여코드로 참여"를 눌러 들어옵니다.
4. 이후부터는 같은 학교 구성원끼리 실시간으로 공유되는 달력을 사용합니다.
5. 각 항목은 작성자 본인 또는 관리자(교무부장)만 수정·삭제할 수 있습니다.

로그인은 구글 계정 없이 브라우저별로 자동 발급되는 "참여자 ID"(Firebase 익명 인증)로 이루어집니다.
브라우저의 참여 정보를 초기화하면(상단 로그아웃 버튼) 새 참여자로 인식되어, 이전에 작성한 항목은
더 이상 본인이 수정할 수 없게 됩니다(항목 자체는 삭제되지 않고 남아 있습니다).

## 데이터/인프라

- **인증**: Firebase Authentication (익명 인증)
- **데이터베이스**: Firebase Firestore — 학교(`schools/{schoolId}`)별로 완전히 분리 저장,
  보안 규칙으로 같은 학교 구성원만 읽기/쓰기 가능하도록 제한
- **호스팅**: Firebase Hosting (`school-monthly-planner.web.app`)
- Firebase 프로젝트: `school-monthly-planner`

## 로컬에서 실행하기

빌드 과정이 없는 순수 HTML/CSS/JS 앱입니다.

```bash
# 프로젝트 폴더에서
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. (파일을 더블클릭해 `file://`로 직접 열면 Firebase 모듈 로딩이
정상 동작하지 않을 수 있으니 로컬 서버로 여는 것을 권장합니다.)

## 배포하기

코드는 GitHub 저장소에서 관리하고, 실제 서비스는 Firebase Hosting으로 배포합니다.

```bash
firebase deploy --only hosting --project school-monthly-planner
```

Firestore 보안 규칙을 변경한 경우:

```bash
firebase deploy --only firestore:rules --project school-monthly-planner
```
