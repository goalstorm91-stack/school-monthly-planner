# 월중계획 대시보드 (School Monthly Planner)

초등학교 교무부장교사가 매월 작성하는 **월중계획**을 관리하기 위한 대시보드 웹앱입니다.
행사, 교직원 복무(출장·연수 등), 처리해야 할 공문을 날짜별로 등록하면 달력 형태로 한눈에 볼 수 있고,
결재용 월중계획표(A4 가로)로 바로 인쇄할 수 있습니다.

## 주요 기능

- **대시보드 달력**: 이번 달 행사 / 복무 / 공문을 색상으로 구분해 달력에 표시
- **날짜 클릭 → 빠른 등록**: 날짜를 클릭하면 그 날의 일정을 보고, 바로 행사/복무/공문을 추가 가능
- **복무 관리**: 대상자, 직위(교장/교감/교무부장/교사/행정직원 등), 구분(출장/연수/조퇴/병가 등), 기간(시작~종료) 기록
- **공문 관리**: 제목, 발신 부서, 처리 상태(처리중/완료) 기록
- **요약 카드**: 이번 달 행사·복무·공문 건수, 처리 대기 공문 건수를 한눈에 표시
- **인쇄용 월중계획표**: 상단 결재란(담당/교무부장/교감/교장)이 있는 A4 가로 표 형식으로 인쇄
- **데이터 백업/복원**: JSON 파일로 내보내기·가져오기 (다른 컴퓨터로 이전 가능)

## 데이터 저장 방식

이 앱은 별도의 서버나 데이터베이스 없이 **브라우저의 localStorage**에 데이터를 저장하는 정적 웹앱입니다.
- 같은 브라우저·같은 컴퓨터에서는 새로고침해도 데이터가 유지됩니다.
- 다른 컴퓨터/브라우저에서 이어서 작업하려면 "내보내기"로 JSON 백업 파일을 저장한 뒤, 그 컴퓨터에서 "가져오기"로 불러오세요.
- 여러 사람이 동시에 같은 데이터를 편집하는 용도가 아니라, **교무부장 1인이 사용하는 개인 업무 도구**로 설계되었습니다.

## 로컬에서 실행하기

빌드 과정이 없는 순수 HTML/CSS/JS 앱입니다. 아래 중 편한 방법으로 실행하세요.

```bash
# 프로젝트 폴더에서
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

또는 VS Code의 Live Server 확장 등으로도 바로 열 수 있습니다.
(파일을 더블클릭해 `file://`로 직접 열면 일부 브라우저에서 정상 동작하지 않을 수 있으니, 위와 같이 로컬 서버로 여는 것을 권장합니다.)

## GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, 폴더는 `/ (root)`로 설정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.
